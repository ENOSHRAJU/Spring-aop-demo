# Spring AOP Demo Application

## 🚀 Overview
This project demonstrates Spring Boot AOP (Aspect-Oriented Programming).

## 🔧 Concepts Implemented
- @Aspect
- @Before advice
- @After advice
- @Around advice
- Logging aspect

## 🛠 Tech Stack
- Java 17
- Spring Boot
- Spring AOP
- Maven

## ▶️ How to Run
1. Clone the repository
2. Run using:
   mvn spring-boot:run
